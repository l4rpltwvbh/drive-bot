⚡ Auto-Login bhi available hai — zyada aasan!
ℹ️ Cookies Kya Hain Aur Kyun Chahiye?
Quick Samajh

Jab aap drive.google.com pe login karte hain, browser ek "session cookie" save karta hai jo batata hai ki aap logged-in hain. Bot ko yeh wahi cookie chahiye taaki woh aapke Drive account ki files aapki taraf se access kar sake — password kabhi nahi chahiye hota, sirf cookie.

✅ Zaroori cookies: SID, HSID, SSID, APISID, SAPISID, __Secure-1PSID, __Secure-3PSID waghaira — isliye poori cookie list export karein, sirf ek do cookie kaafi nahi hoti.
⚠️ Incognito / Private mode mein login karke cookies mat nikalein — woh session band hote hi expire ho jaati hain. Normal (non-incognito) window mein login karke hi cookies export karein.

YA — Terminal Method (Advanced)
⚙️ Advanced — Terminal
SQLite Cookie Extraction
Chrome cookie database se directly cookies nikaalein (encrypted nahi hoti Linux pe).
1
Terminal mein yeh command run karein:
sqlite3 ~/.config/google-chrome/Default/Cookies \ "SELECT name, value FROM cookies WHERE host_key LIKE '%google.com%';"

Chromium ke liye: ~/.config/chromium/Default/Cookies

⚠️ Chrome band hona chahiye — warna DB locked rahega. Modern Chrome encrypted cookies save karta hai jo is method se nahi milenge.

copy(JSON.stringify(document.cookie.split('; ').reduce((a,c)=>{const[k,...v]=c.split('=');a[k]=v.join('=');return a},{}),null,2))

Cookies PC ki clipboard mein aa jaayengi

YA — Desktop Mode Trick
💡 Method 3 — Desktop Mode Bookmarklet
Chrome Desktop Mode + Bookmarklet
Chrome Android mein Desktop Mode on karein aur bookmarklet se cookies nikaalein.
1
Chrome Android mein drive.google.com kholein

⋮ → Desktop site enable karein.

2
Address bar mein yeh paste karein aur Enter dabao:
javascript:(function(){/* loading... */})()

Page automatically bot ke server pe redirect ho jaayega — cookies copy-paste ki zarurat nahi!

⚠️ Important: JavaScript sirf non-HttpOnly cookies de sakta hai. Google Drive ke liye __Secure-1PSID aur __Secure-3PSID bhi chahiye jo HttpOnly hain — JS se inaccessible hain. Private files ke liye Method 1 (Kiwi + J2Team) ya Auto-Login use karein.
